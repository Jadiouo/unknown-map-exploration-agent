# Reproducing the public tests

The original homework and public grader are preserved in the offline project ZIP. Place `submission/agent.py` over the homework's `HW2/agent.py` in a local copy, then run its `public_grader.py` according to `original_assignment/HW2/README.md`.

The public test results reported in the project are 56, 85, and 100 steps (zero collisions), respectively. See `research/RESEARCH_REPORT.md` for the experiment conditions and limitations.

Note: the original homework assets and PNG visualizations are not yet uploaded to this repository; refer to the local project archive until they are added.
